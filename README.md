# Cybersecurity-journey
Hands-on cybersecurity journey — networking, Linux, Active Directory, SIEM, detection, incident response and security labs.

🎯 Objetivo deste repositório

Registrar, de forma organizada e verificável, cada laboratório, projeto e aprendizado da transição — para consulta própria, para acompanhamento de evolução, e para qualquer recrutador/gestor técnico que queira ver como eu penso e documento meu trabalho.

🗺️ Roadmap em andamento
 Setup do ambiente — VirtualBox + Ubuntu 24.04 LTS
 Fundamentos de Linux (TryHackMe — Pre Security)
 Home Lab de rede: Wireshark + Nmap
 Active Directory vulnerável (Windows Server + cliente)
 SIEM — Wazuh monitorando o ambiente do lab
 Sysmon + análise de eventos no Windows
 Projeto "Home SOC" — Wazuh + AD + regras de detecção
 Certificação CompTIA Security+
🧰 Stack e ferramentas em uso

VirtualBox · Ubuntu 24.04 LTS · Windows Server/Cliente · Kali Linux · Wireshark · Nmap · Wazuh · Sysmon · PowerShell · Bash
